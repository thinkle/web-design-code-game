## Make the kitty happy!

Use the margin property to help the kitten get 
away from the water and into the shade!

### Hint
You can use `margin-right`, `margin-left`, `margin-top` and `margin-bottom` to specify
which direction to use!

## Margins can be `auto`

How far is it to the umbrellas? That depends on how wide the screen is,
so a fixed number of pixels might work on your screen and miss on your
neighbor's!

Instead of a number, a margin can be `auto`, which means "take up all
the leftover space." An `auto` margin on one side pushes a box (one with
a set width) all the way to the other side:

```css
selector {
  margin-left: auto; /* push all the way to the right */
}
```

Try using `auto` to get the cat to the umbrellas, however wide the
beach is.
