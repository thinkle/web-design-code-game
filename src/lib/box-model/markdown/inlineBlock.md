# Inline-Block Challenge

Oh no! The cats are all in a vertical line, and they can't see each other! Help them stand side by side so they can have a friendly chat.

Keep the `margin: 16px` that's already there so they stay a friendly
distance apart!

## Display: inline-block

Boxes like these normally stack on top of each other, each on its own
line. You can change that with the `display` property:

```css
selector {
  display: inline-block;
}
```

An `inline-block` element is still a box (it keeps its width, height,
padding and margin), but it sits in a line next to its neighbors, the way
words sit next to each other in a sentence.
