# Sun Salutation

Every cat yoga class starts with a sun salutation! ☀️ The sun is shining through the window and making a warm sunbeam in the **middle** of the rug, and all three cats want to stretch out in it.

## justify-content

Once an element is a flex container, `justify-content` decides where its items go along the row: at the start, in the middle, or at the end.

```css
.menu {
  display: flex;
  justify-content: start;
}
```

Some values you can use:

| value | where the items go |
|-------|--------------------|
| `start` | bunched up at the start (the default) |
| `center` | bunched up in the middle |
| `end` | bunched up at the end |

## Goal

Move all three cats into the sunbeam, like the Target. Change the **rug** (the container), not the cats!
